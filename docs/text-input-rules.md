# 글로 입력해서 올리기 — 읽기 규칙

> 장보기 올리기 화면의 "글로 입력해서 올리기"(CLAUDE.md 4-1, FR-04/05)가 입력을 어떻게 읽는지 정한 문서예요.
> 아래 **예시 표는 테스트가 그대로 읽어서 검사**해요 (`src/rules/textInput.test.ts`). 예시를 고치거나 추가하면 테스트도 같이 바뀌어요.
> 나중에 AI를 붙여도 같은 표로 결과를 비교해요.

## 1. 항목 나누기

- 줄바꿈, 쉼표(`,`), `그리고`로 나눈다.
- 빈 항목은 무시한다 (`대파 1봉,, ` → 1줄).
- `랑`, `하고`로는 나누지 않는다. (`고기랑` 같은 단어를 잘못 자를 수 있어서, 이번 범위에서는 제외)
- 같은 재료를 두 번 쓰거나 이미 냉장고에 있는 재료여도 **합치지 않고 따로** 넣는다. 입고일이 다르면 소비기한도 달라서다.

## 2. 한 항목 읽기

한 항목은 **재료 이름 + 개수 + 단위 + (소분)** 으로 이루어지고, 순서는 섞여도 된다 (`대파 소분 한봉지`, `소분 닭가슴살 세봉지`).
띄어쓰기는 달라도 된다 (`세봉지` = `세 봉지`, `닭가슴살세봉지소분`도 읽는다).

### 2-1. 개수

- 아라비아 숫자 (`3`, `30`)
- 한글 수사: 한/하나(1), 두/둘(2), 세/셋/석(3), 네/넷/넉(4), 다섯(5), 여섯(6), 일곱(7), 여덟(8), 아홉(9), 열(10)
- **한글 수사는 단위 바로 앞(붙거나 한 칸 띄움)에 있거나, 홀로 떨어진 낱말일 때만 숫자로 읽는다.**
  - `두부`의 "두", `한우`의 "한", `열무`의 "열"을 숫자로 잘못 읽지 않기 위해서다.
- 개수 범위는 **1~30**. 0이나 30보다 크면 못 읽은 것으로 보고 다시 묻는다.
- 무게·부피(`400g`, `1kg`, `900ml`, `1.5L`)는 개수가 아니다. **메모**로 따로 둔다.

### 2-2. 단위

- 봉/봉지 → `봉`, 덩어리/덩이 → `덩이`, 개, 팩, 통, 구, 단, 모
- 단위는 **숫자 바로 뒤**에 있거나 **홀로 떨어진 낱말**일 때만 단위로 읽는다. (`단호박`의 "단", `김치찌개`의 "개"는 단위가 아님)
- 숫자만 있고 단위가 없으면 `개`로 본다 (`우유 2` → 2개).

### 2-3. 소분

- 입력에 `소분`이라는 말이 들어 있으면 소분 품목이다 (`소분함`, `소분해서`, `소분했어` 모두 포함).
- 없으면 포장 그대로인 품목이다 (기본값은 소분 안 함).
- "나눠서" 같은 다른 표현은 이번에는 읽지 않는다.

### 2-4. 개수를 못 읽었을 때

| 경우 | 처리 |
|---|---|
| 소분인데 개수가 없음 | 그 줄만 **"몇 개로 나눴나요?"** 로 묻는다 (숫자 선택) |
| 소분이 아닌데 개수가 없음 | 포장 그대로 **1개** (`삼겹살 600g` → 1개, 메모 600g) |
| 숫자 말이 있는데 읽지 못함 (`계란 한판`, `닭가슴살 두세봉`) | 조용히 1개로 두지 않고 **"몇 개인가요?"** 로 묻는다 |

개수를 묻는 줄(`?개`)에는 빠져나갈 길 두 개를 둔다 (2026-10-30, 수정명세 v2 A-8):
- **잘 모르겠어요 (1개로 둘게요)**: 개수를 1로 채우고 확인 표시를 푼다. 소분 여부는 그대로.
- **소분 안 함으로 바꾸기** (소분 줄만): 소분을 끄고 포장 그대로 1개. 보관 위치·소비기한도 소분 안 한 기준으로 다시 계산한다(직접 고친 소비기한은 그대로).

### 2-5. 재료 이름

- 재료 사전(`src/data/catalog.json`)에서 **가장 길게 일치하는 이름**을 찾는다. 띄어쓰기는 무시하고 비교한다.
  - `돼지고기 앞다리살` → "돼지고기 앞다리살" (돼지고기 아님), `적양파` → "적양파" (양파 아님), `찌개두부` → "찌개두부"
- 이름 **바로 뒤에 다른 글자가 붙어 있으면**(개수·단위·소분·무게가 아닌 글자) 낱말 중간에서 끊긴 것으로 보고, 다른 후보를 먼저 쓴다.
  - `냉동새우살` → "새우살" ("냉동새우"는 더 길지만 뒤에 "살"이 붙어 있어서 뒤로 밀림)
  - `닭가슴살세봉지` → "닭가슴살" (뒤에 붙은 "세봉지"는 개수·단위라 괜찮음)
- 사전의 **다른 이름**(`aliases`)도 같은 재료로 찾는다 (`달걀` → 계란, `쇠고기` → 소고기, `앞다리살` → 돼지고기 앞다리살). 다른 이름은 같은 재료를 부르는 말만 넣고, 비슷하지만 다른 재료(파↔양파, 대파↔쪽파)는 넣지 않는다.
- 사전에서 찾으면 **사전 이름으로 바꿔서** 보여준다 (`국산 닭가슴살` → 닭가슴살, `냉동새우살` → 새우살).
- 사전에 없으면 개수·단위·소분·무게를 뺀 나머지 글자를 이름으로 쓰고, **"소비기한을 골라 주세요"** 로 묻는다.
  - 낱말 중간에서 끊긴 후보밖에 없을 때도 사전에 없는 것으로 본다 (`두부과자` → 이름 "두부과자", 후보 칩 "두부").

### 2-6. 헷갈린 줄 표시 ("이름을 확인해 주세요")

규칙으로 읽는 이상 틀릴 수 있으므로, 헷갈린 줄은 표시해서 사용자가 보고 고치게 한다.

- 고른 이름 **안에 포함되지 않는** 다른 사전 이름이 같이 걸렸으면 표시한다.
  - `냉동새우살` → 새우살을 골랐지만 "냉동새우"도 걸림 → 표시. 후보 칩: 새우살, 냉동새우
  - `대파 양파 1개` → 쉼표를 빠뜨린 경우. 대파를 골랐지만 "양파"도 걸림 → 표시
  - `적양파`의 "양파", `돼지고기 앞다리살`의 "돼지고기"는 고른 이름 안에 들어 있으므로 표시하지 않는다.
- 낱말 중간에서 끊긴 후보밖에 없을 때 (`두부과자`) 표시한다.
- 같은 길이면 앞에 나온 이름을 고른다.

## 3. 읽은 뒤 (확인 화면)

- 읽은 결과는 반드시 목록으로 한 번 보여주고 확인을 받는다 (바로 저장하지 않음).
- 각 줄에서 고칠 수 있는 것:
  - **이름**: 이름을 누르면 후보 칩(같이 걸린 사전 이름)이 나오고, 없으면 직접 입력한다. 이름을 바꾸면 소비기한·보관 위치를 다시 계산한다.
  - 개수(± 버튼, 1~30), 소분 여부, 보관 위치, 소비기한(±1일)
  - **줄 삭제** (잘못 나뉜 줄)
- 헷갈린 줄(2-6), 개수를 못 읽은 줄, 소비기한을 골라야 하는 줄은 표시해서 눈에 띄게 한다. 이런 줄이 남아 있으면 "냉장고에 넣을게요"를 누를 수 없다. 단, "이름을 확인해 주세요"는 사용자가 이름을 그대로 두기로 할 수 있다(확인 버튼).
- 소분 품목: 입고일 = 오늘(소분한 날), 기본 보관 위치는 육류·해산물·냉동식품이면 냉동, 그 외는 품목 기본 위치. 소비기한은 소분 기간표(임시).
- "냉장고에 넣을게요"를 누르면 재고에 넣고 이번 주 화면으로 간다.

### 저장한 뒤에 고치기 (냉장고 → 재료 시트)

- **잘못 넣었어요**: 재료를 지운다. "버렸어요"와 달리 버린 기록으로 세지 않는다.
- **보관 위치 바꾸기** (냉장/냉동/실온)
- **소분 개수 ±** (소분 품목만, 1~30)
- 이름은 저장 뒤에 바꾸지 않는다. 틀렸으면 "잘못 넣었어요"로 지우고 다시 넣는다.

## 5. 예시 — 여러 항목 나누기
