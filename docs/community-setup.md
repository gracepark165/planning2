# 커뮤니티 서버 연결하기

카카오 로그인과 함께 한 번에 연결하도록 **`docs/server-setup.md`**로 옮겼어요.

## 커뮤니티 구조

- 서버 함수: `api/community.ts` (POST `/api/community` 글·공감·댓글·프로필·랭킹, GET `/api/community?img=ID` 사진). 저장소는 Upstash Redis.
- 앱: `src/community/` (서버 호출·예시 글·사진 줄이기·로그인 상태), 화면 `src/ui/CommunityView.tsx`
- 로그인(2026-11-16): 카카오 로그인 쿠키로 작성자를 구분해요. 로그인하지 않은 방문자는 읽기만 해요.
- 제한: 글 500자, 댓글 200자, 사진은 640px JPEG로 줄여서 올림, 하루 글 20개·댓글 100개.
- 랭킹: 최근 7일 글 중 공감 많은 순 3개 (공감 0개는 빼요).

## 아직 없는 것

신고·차단, 글 고치기, 댓글 지우기, 알림. 공개 서비스로 열기 전에는 신고 기능과 운영 방침이 필요해요.
