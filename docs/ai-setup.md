# AI 연결하기 (7-2)

> 코드는 다 준비돼 있어요. **키만 넣으면** 켜져요. 키가 없을 때는 지금처럼 예시 결과·직접 입력으로 동작해요.

## 1. 키 만들기

| 키 | 어디서 | 꼭 필요? |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys → Create Key | 필수 |
| `YOUTUBE_API_KEY` | console.cloud.google.com → 새 프로젝트 → "YouTube Data API v3" 사용 설정 → 사용자 인증 정보 → API 키 | 선택 (없으면 영상 **제목만** 읽음) |

- Anthropic 콘솔 → **Billing → 월 사용 한도(spend limit)** 를 꼭 걸어 두세요. 비용을 지키는 가장 확실한 방법이에요.
- 유튜브 키는 "API 제한사항"에서 YouTube Data API v3만 쓰도록 제한해 두면 안전해요.
- 키는 **채팅·코드·깃허브에 넣지 않아요.**

## 2. Vercel에 넣기

1. Vercel → planning2 → **Settings → Environment Variables**
2. 이름 `ANTHROPIC_API_KEY`, 값 = 키, 환경은 Production·Preview 모두 체크 → Save
3. (선택) `YOUTUBE_API_KEY`도 같은 방법으로
4. **Deployments → 맨 위 배포의 ⋯ → Redeploy** ← 키는 다시 배포해야 적용돼요

## 3. 확인하기

| 해볼 것 | 기대 결과 |
|---|---|
| 장보기 올리기 → 주문 화면 사진 올리기 | "N개를 찾았어요" + 줄마다 "AI가 읽었어요", 마트·입고일 자동 |
| 글 입력: `계란 한판, 우유 2개` | 계란 30구 "AI가 읽었어요" (규칙이 못 읽은 줄만 AI가 봄) |
| 영상 확인: 설명란에 재료가 있는 롱폼·쇼츠 링크 | "‘메뉴’ 영상이 맞나요?" → 결과·대체 제안 |
| 영상 확인: 설명란이 빈 쇼츠 | "메뉴 이름으로 흔히 쓰는 재료를 짐작했어요" (유튜브 키가 없을 때도 이렇게 나옴) |

키를 넣었는데도 "AI 연결 전이라…"가 나오면 2-4(다시 배포)를 했는지 확인해요.

## 4. 내 컴퓨터에서 시험하기 (선택)

`.env.example`을 복사해 `.env.local`을 만들고 키를 넣은 뒤 `npm run dev`. 개발 서버가 `/api/read`를 대신 실행해요.

## 구조

```
앱(src/ai/client.ts) → POST /api/read (api/read.ts, Vercel 서버 함수, 키는 여기만) → Claude
                                   └ 영상이면 먼저 유튜브(설명란 또는 제목)
앱(src/ai/convert.ts): AI 결과를 걸러서 확인 화면 줄·영상 메뉴로 바꿈 (이름은 재료 사전으로, 숫자·날짜는 범위 확인)
```

- 모델: `claude-sonnet-5-5` (`api/read.ts`의 `AI_MODEL`)
- AI가 하는 일은 **읽기**뿐: 주문 사진 → 재료, 영상 제목·설명란 → 메뉴·재료, 규칙이 못 읽은 글 줄 → 재료.
  상태 판정·소비기한·이번 주 플랜·대체 제안은 규칙 코드 그대로.
- 읽은 결과는 항상 확인 화면을 거친다 (바로 저장하지 않음).
- 긴 캡처는 앱이 최대 4조각으로 잘라 보낸다 (AI가 한 장을 작게 줄여 글자를 놓치지 않게).
- 같은 사람(IP)이 10분에 20번 넘게 부르면 잠깐 막는다. 서버 인스턴스마다 따로 세는 대략적인 제한이라, 비용 상한은 콘솔의 월 한도로 지킨다.
- AI는 유튜브 영상을 직접 보지 못한다. 설명란에 재료가 없으면 메뉴 이름으로 짐작하고, 그렇다고 화면에 알린다. 틀리면 "고칠게요"로 직접 입력 화면에 채워 준다.
